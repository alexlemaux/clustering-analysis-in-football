The purpose of my project is to cluster football games by applicating machine learning to game data statistics. By combining 2 algorithms (principal component analysis and k means clustering), 
the result classify the games into 4 differents clusters, thoses clusters can be vizualised into 3D.
The data set group many different statistics of football games per teams. Data had been all downloaded from Fbref and grouped in one single csv file. 
The dataset groups 8087 team’s games. It represents the teams of 15 different domestic competitions from France, Germany, Spain, England, Italy, Portugal, Belgium,
Netherlands, Brazil, and Mexico. Each game is characterized by 156 features. The dataset is data collected from different football games in 2023-2024 season.
